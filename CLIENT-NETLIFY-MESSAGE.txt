Hi, here is the Wood Origins website package for Netlify:
https://github.com/fakhridhinanta/wood-origins-ecommerce-web

Please use the Netlify-ready version containing netlify.toml and the netlify-app folder.

1. In Netlify, choose Add new project → Import an existing project → GitHub, then select the repository and main branch. You will need access to the private repository.
2. Keep the build settings from netlify.toml; do not select the Next.js preset.
3. Add ADMIN_LOGIN_ID, ADMIN_LOGIN_PASSWORD, and PABBLY_WEBHOOK_URL as server environment variables. We will share their values privately.
4. Deploy. The package includes Netlify Database setup and migrations; please use an account with Netlify Database support. If Netlify prompts you to enable the database, enable it under Data & Storage → Database and redeploy.
5. Check the website and /admin, submit a test quote using ?test=1, and then verify one labeled live enquiry reaches Airtable/Pabbly before connecting the production domain.

Full setup and verification steps are in NETLIFY-SETUP.md. The new database starts empty; existing records/settings in the current hosting do not move automatically.
